## Autoridad física

`validate_published_resources` valida primero los cruces estructurales entre
`effective-config.json`, `manifest.json` y el catálogo. Después relee los bytes
enlazados y reutiliza las fronteras canónicas existentes:

- `validate_supplied_fasta` para orden, IDs, clase, longitud y número de `N`;
- `generate_reference` para reproducir base a base una referencia simulada;
- `derive_subseed`, `select_reduced_reference` y `materialize_selection` para
  reconstruir la selección declarada;
- `build_reduced_reference`, `reduction_map_document` y
  `validate_reduction_map_document` para contrastar FASTA derivado y mapa.

La prueba correlacionada parte de árboles `complete`, modifica declaraciones y
recursos y recalcula tamaño/SHA-256. Sus cinco casos cubren `region_size_bases`,
IDs fuente, longitud/tamaño, composición y mapa. Todos conservan un manifiesto
estructuralmente válido, pero la autoridad física los rechaza con
`GPS-FMT-006`.

La regresión E2E altera un FASTA simulado y actualiza el catálogo antes de que
el orquestador escriba el manifiesto. El fallback resultante es un árbol
`failed` real con diagnóstico canónico, sin `effective-config.json` ni su ID.
El seam de mutación está limitado a `#[cfg(test)]`; no añade hooks de producción
ni restaura el modelo de atacante local de F9.

## Catálogo diagnóstico

El productor y el validador Rust consultan una única tabla runtime para código,
categoría, significado y salida. El gate compara todos los códigos activos de
`src` con `catalogs/diagnostics-v2.tsv` y también prueba aceptación del mensaje
canónico y rechazo del alterado. El oráculo Python lee directamente el TSV y,
además del JSON Schema, exige que cada diagnóstico `failed` exista y conserve
su significado. Hay negativos explícitos para `GPS-FMT-999` y para mensaje
autofirmado, más un positivo catalogado.

La suite enumeró 139 casos: 138 pasaron y el helper exclusivo de subprocesos

--no-fetch` cargó 1216 avisos, examinó 65 paquetes y no informó
vulnerabilidades; avisó que no pudo tomar el lock del índice local. El árbol de
dependencias no contiene `jsonschema` runtime.
