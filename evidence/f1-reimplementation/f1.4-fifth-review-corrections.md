## Autoridad TOML completa

La relectura del TOML reconstruye `EffectiveConfig` con el mismo constructor
tipado. Si la semilla estaba declarada debe coincidir literalmente; si estaba
ausente se inyecta para la reconstrucción la raíz CSPRNG publicada y se exige
origen `system_csprng`. Se comparan fuente e ID de referencia, composición,
tamaño, secuencias ordenadas, clases, longitudes y todos los campos declarados o
derivados de cada reducción, incluidas región, objetivo y subsemilla.

La regresión altera la copia TOML con configuraciones válidas que cambian una a
una semilla, región, referencia, clase o composición, recalcula el registro del
catálogo y mantiene los demás documentos/recursos autoconsistentes entre sí. La
autoridad TOML independiente rechaza los cinco casos.

## Categorías disjuntas

El parser conserva un conjunto global durante la lectura de `minimum`,
`defaulted`, `requested` y `disabled`; un ID no puede aparecer en dos listas.
También rechaza que el enlace FASTA fuente y derivado de una reducción sean el
mismo artefacto. La regresión diferencial crea exactamente ese alias y exige
rechazo tanto de Rust como del oráculo Python.
